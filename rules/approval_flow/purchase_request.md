The direct manager approves. Above 10,000 the general manager countersigns after the manager. A request with unpriced lines goes back to the submitter for quotations before any approval. The last approval is final: set the request to approved.

直属经理审批。金额超过 10000 的，经理通过后由总经理会签。含未报价行的申请，先退回提交人补报价，再进入审批。最后一个通过即为最终：申请置为 approved。
