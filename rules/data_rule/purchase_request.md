Each line names the product or a clear specification, a quantity and a needed-by date. A request above 5,000 attaches a quotation. The purpose is stated in one sentence.

每行写明产品或清楚的规格、数量和需用日期。金额超过 5000 的申请附报价单。用途用一句话说清。
